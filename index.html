Etiqueta <br>

La etiqueta <br> inserta un salto de línea dentro de un texto sin necesidad de iniciar un nuevo párrafo.

Etiqueta <hr>

La etiqueta <hr> se utiliza para representar una separación temática o una línea horizontal entre bloques de contenido.

Etiqueta <img>

La etiqueta <img> sirve para incrustar una imagen en la página web utilizando la ruta del archivo en el atributo src.

Etiqueta <input>

La etiqueta <input> permite crear campos interactivos dentro de un formulario para que el usuario introduzca datos.

Etiqueta <link>

La etiqueta <link> se coloca en el <head> y sirve para enlazar recursos externos como hojas de estilo CSS a la página web.

Etiqueta <meta>

Las etiquetas <meta> se ubican en el <head> y definen metadatos sobre el documento: la codificación de caracteres (charset), la vista adaptativa para móviles (viewport) o la descripción del sitio para motores de búsqueda.
