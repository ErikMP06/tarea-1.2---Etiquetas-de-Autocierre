Etiqueta <br>

La etiqueta <br> inserta un salto de línea dentro de un texto sin necesidad de iniciar un nuevo párrafo.

Etiqueta <hr>

La etiqueta <hr> se utiliza para representar una separación temática o una línea horizontal entre bloques de contenido.

Etiqueta <img>

La etiqueta <img> sirve para incrustar una imagen en la página web utilizando la ruta del archivo en el atributo src.

Etiqueta <input>

La etiqueta <input> permite crear campos interactivos dentro de un formulario para que el usuario introduzca datos.

Etiqueta <link>

La etiqueta <link> se coloca en el <head> y sirve para enlazar recursos externos como hojas de estilo CSS a la página web.

Etiqueta <meta>

Las etiquetas <meta> se ubican en el <head> y definen metadatos sobre el documento: la codificación de caracteres (charset), la vista adaptativa para móviles (viewport) o la descripción del sitio para motores de búsqueda.

Etiqueta <col>

La etiqueta <col> se utiliza dentro de un grupo <colgroup> en una tabla para definir propiedades o estilos comunes a columnas completas.

Etiqueta <embed>

La etiqueta <embed> sirve como contenedor para incrustar recursos externos interactivos o multimedia como aplicaciones, archivos PDF o imágenes SVG.

Etiqueta <param>

La etiqueta <param> se usaba dentro de elementos <object> para definir parámetros de configuración en applets o plugins (como Flash o Java). Actualmente está obsoleta y los navegadores modernos ignoran su efecto visual.

Etiqueta <source>

La etiqueta <source> se utiliza dentro de elementos de medios como <video> o <audio> para especificar múltiples archivos o formatos multimedia alternativos.

Etiqueta <wbr>

La etiqueta <wbr> (Word Break Opportunity) especifica una posición dentro de un texto donde el navegador puede realizar un salto de línea opcional si la ventana se estrecha demasiado.
