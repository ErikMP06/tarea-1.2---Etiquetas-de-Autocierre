Etiquetas de autocierre by Erik

Etiqueta <br>

La etiqueta <br> inserta un salto de línea dentro de un texto sin necesidad de iniciar un nuevo párrafo.

Primera línea de texto.
Segunda línea de texto tras el salto.

Etiqueta <hr>

La etiqueta <hr> se utiliza para representar una separación temática o una línea horizontal entre bloques de contenido.

Etiqueta <img>

La etiqueta <img> sirve para incrustar una imagen en la página web utilizando la ruta del archivo en el atributo src.
